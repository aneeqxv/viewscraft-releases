# ViewsCraft releases

This repository only holds **ViewsCraft installers and update files**. There is no app code here.

- **New members:** open [Releases](https://github.com/aneeqxv/viewscraft-releases/releases/latest) and download `ViewsCraft-Setup-<version>.exe`.
- **Existing members:** nothing to do. ViewsCraft checks this page for updates by itself, downloads them in the background, and installs them when you close the app.

Files in each release:

| File | What it is |
| --- | --- |
| `ViewsCraft-Setup-<version>.exe` | The Windows installer |
| `ViewsCraft-Setup-<version>.exe.blockmap` | Lets the updater download only the changed parts |
| `latest.yml` | Tells installed copies which version is newest |
